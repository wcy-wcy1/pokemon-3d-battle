# 宝可梦战斗项目共享笔记

## 游戏目标

让玩家看清谁在行动、招式是否命中、何时可以再次输入。优化模型、动作和场景时，在对应 PR 中给出可观察的验收条件，例如攻击前的预备动作、命中反馈、倒地后换人以及手机上是否看得清 HUD。

## 如何交接

- 开工时阅读本页和对应 PR 的最新说明、提交及测试评论。Wiki 只记录长期约定；编辑本页不会派发任务。
- ll 在 PR 记录改动、预期行为和需要验证的场景，完成后在 Discord 明确提及 Codex，附上完整提交号。
- Codex 获取指定 PR，核对提交号，在本机运行相关检查。验收评论注明完整提交号、实际运行的检查、失败和跳过项。截图留在本机时注明这一点。
- 全部通过则在频道收尾。已验证的代码缺陷交回 ll；环境阻塞或需要决定的问题交给机主。同一提交的重复消息不启动新验收。
- 长期有效的结论随相关 PR 更新本页。单次结果留在对应 PR，避免把旧版本的结论用于新提交。

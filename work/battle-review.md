# 最终单文件战斗核验

运行入口：`outputs/index.html`。以下检查使用本机 Chrome、Three.js r128 和真实图鉴模型，在 file:// 页面运行；定步长推进对战可以对齐骨骼、特效和命中帧。验证范围不含所有设备的帧率或所有场景组合。

| 检查 | 观察与证据 |
| --- | --- |
| 超梦 J 念力 | 先命中出描边，再按目标体重同步抬手与浮空。用真实指针进行左、右、前、斜向投掷；断言指骨瞄准、抬腕曲线、挥手时尚未脱手、前臂与投射方向一致及落地清理。`palmtest.cjs`、`gripgesturetest.cjs`；[四帧实机对照](../outputs/mewtwo-grip.jpg)。 |
| 图鉴尺度与镜头 | 50 个模型使用同一米制比例；长身模型按身体骨链计长。横竖屏、侧视和纵深构图对小体型及长体型抽样验证。[镜头对照](../outputs/duel-camera.jpg)。 |
| 姿态与受力 | 50 只实测接敌戒备与施法过渡、冲击传递与恢复；轻重体型的回弹幅度和时序不同。[受击对照](../outputs/recoil-comparison.jpg)。 |
| 命中与躲避 | 50 种普攻近距可命中，50 种属性招式能命中或造成睡眠，也能通过预先侧移避开。逐种记录在同目录的 roster-*-results.json；命中检查不代表每一种招式都有独立的全套骨骼动画。 |
| 技能辨识 | [前 25 种](../outputs/roster-cast-1.jpg)、[后 25 种](../outputs/roster-cast-2.jpg)为属性招式取帧。皮卡丘 J 单独实测尾部变白、甩尾近距只命中一次、距离不足时挥空、收招复色。[铁尾序列](../outputs/iron-tail.jpg)。 |
